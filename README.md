# Python Study Notes

These are my personal study notes from learning Python and using it to solve practical programming problems. They collect the language concepts, standard-library patterns, and development habits I want to revisit while studying and working.

The notes target Python 3.14 and use examples that can be run with the standard library unless a chapter says otherwise. The chapters build from values and control flow toward modules, testing, concurrency, and a small command-line project.

## How I use these notes

I keep each chapter focused on a small group of related ideas. Examples show the input, the Python construct being used, and the result or behavior to expect. The capstone combines several concepts in one small program so the language features have a practical context.

The last chapters collect the examples and answered review questions for quick revision. I update these notes as I test the code and learn better ways to use Python.
